# 🎓 Student Management System - Java

A Java-based desktop application to manage student records efficiently using MySQL database. This project performs all CRUD operations.

### ✨ Features
- Add New Student
- Update Student Details
- Delete Student Record
- View All Students
- Search Student by ID/Name

### 🛠️ Tech Stack
- **Language:** Java (Core Java, Swing)
- **Database:** MySQL
- **Concepts Used:** JDBC, OOPs
- **IDE:** VS Code

### 🚀 How to Run This Project
1. Clone this repository
2. Create a database `studentdb` in MySQL
3. Create `students` table
4. Open `DBConnection.java` and update your MySQL username & password
5. Compile and Run `StudentManagementSystem.java`
